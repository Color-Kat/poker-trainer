# Тренажёр покера (No-Limit Texas Hold'em)

Обучающий тренажёр для начинающего игрока перед первым живым турниром. На ключевых решениях
задаёт вопросы (ауты, эквити по правилу 2 и 4, шансы банка, действие, чтение соперника) и
разбирает ошибки с конкретными цифрами.

**Играть:** https://color-kat.github.io/poker-trainer/

**Передать другу:** вся игра — один файл [`index.html`](index.html) (≈ 300 КБ, без интернета,
без установки). Скачайте его («Сохранить как…» на странице игры или кнопкой в меню) и
откройте в любом браузере. Карты нарисованы CSS/Unicode, внешних картинок и шрифтов нет.

## Что внутри

- **3 режима:** Обучение (вопрос на каждом решении + подсказки), Тренировка (вопросы
  выборочно, разбор только ошибок), Турнир (растущие блайнды, вылет, разбор ошибок).
- **Стол на 2–9 игроков**, позиции UTG…BB с пояснениями, кнопка дилера по часовой стрелке.
- **Префлоп:** проверка по таблице диапазонов, мини-таблица «Посмотреть диапазон».
- **Флоп/тёрн:** ауты (чистые и «грязные»), правило 2 и 4, шансы банка, правильное действие,
  после раздачи — реальное эквити против настоящих карт соперника.
- **5 стилей ботов:** Камень, Коллинг-станция, Регуляр, Маньяк, Актёр — со своими теллами.
- **Теллы:** «Смотреть на борд / на соперников» при открытии каждой улицы, вопрос
  «Что у соперника?», контроль собственного тайминга.
- **Шпаргалка и статистика** доступны в любой момент; прогресс хранится в браузере.

## Разработка

Исходники — отдельные модули в `src/`, сборка склеивает их в один `index.html`:

```bash
node build.js        # src/*.js + src/*.css + src/template.html → index.html
node tests/run.js    # юнит-тесты (движок, боты, тренер, статистика)
node tools/e2e.js    # автоигра в headless Chromium (нужен playwright-core: npm i)
```

Устройство модулей и их API — в [ARCHITECTURE.md](ARCHITECTURE.md), исходное ТЗ — в [SPEC.md](SPEC.md).
